基于 **Cloudflare Workers** 部署的 **AlwaysData 免费空间自动保活脚本**

---

## 📌 功能说明

* ✅ 多账号自动登录保活，防止空间被暂停  
* ✅ 定时 Cron 触发（每 15 天一次性全量执行）  
* ✅ 网页管理面板，可查看/添加/删除账号  
* ✅ 批量执行及单个执行，状态实时反馈  
* ✅ Telegram 汇总通知（批量结束后一次发送）  
* ✅ 累计成功/失败次数统计  
* ✅ 每个 Worker 最多管理 **10 个账号**，防呆设计，超出可部署多个 Worker

## 🚀 部署方式

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)，进入 **Workers & Pages**  
2. 创建一个新的 Worker，将 [`worker.js`](./worker.js) 代码粘贴进去  
3. 创建 **KV 命名空间**（名称随意），在 Worker 设置中绑定，变量名为 `ALWAYSDATA_KV`  
4. 配置环境变量（见下表）  
5. 部署 Worker  

---

## 🔧 环境变量配置

| 变量名           | 说明                         |
| ---------------- | ---------------------------- |
| `ADMIN_TOKEN`    | 管理面板登录密码             |
| `TG_BOT_TOKEN`   | Telegram Bot Token（可选）   |
| `TG_CHAT_ID`     | Telegram Chat ID（可选）     |

账号数据存储在 **KV** 的 `accounts` 键中。可在部署后通过管理面板添加账号，或直接在 KV 中手动写入。

---

### 📄 账号存储格式（KV）

每行一个账号，用 `-----` 分隔邮箱和密码：

```
your@email.com-----yourpassword
another@email.com-----anotherpassword
```

**注意**：系统只会读取前 10 行，超出的账号不会被处理，如需管理更多账号请部署额外的 Worker。

---

## ⏰ 定时任务（Cron）

在 Cloudflare Workers 的 **Triggers** 中添加 Cron Trigger：

```
0 0 */15 * *
```

👉 每 **15 天** 自动执行一次 **所有可见账号**（最多 10 个），账号之间间隔 2 秒，执行完毕后发送一条 Telegram 汇总通知。

> ⚠️ **免费计划限制**：每个 Cloudflare 账户最多可设置 **5 个 Cron 触发器**。如果你部署了多个 Worker 并分别需要定时任务，请注意触发器总数不要超过此限制。如有需要，可使用外部 Cron 服务（如 cron-job.org）调用 API 触发。

## 🌐 使用方式

### 1️⃣ 浏览器管理面板（推荐）

```
https://你的域名/admin?token=设置的密码
```

面板功能：

* **➕ 添加账号**：邮箱 + 密码，超过 10 个会提示上限  
* **👥 账号列表**：每行显示邮箱（密码脱敏）、实时执行状态（`-` / ⏳ / ✅ 成功 / ❌ 失败）  
* **▶️ 单个执行**：点击该账号的 ▶ 按钮，执行后状态就地更新  
* **🗑️ 删除账号**：点击删除按钮，确认后移除  
* **▶ 批量执行**：点击顶部按钮，依次执行所有账号（间隔 3 秒），每个账号独立请求，结果实时显示，全部完成后自动发送一条 Telegram 通知（若已配置）  
* **📊 统计卡片**：显示总账号数、累计成功/失败次数  

---

### 2️⃣ API 触发所有账号保活（注意请求限制）

```bash
curl "https://你的域名/run-all?token=你的密码"
```

---

### 3️⃣ API 触发指定账号保活

```bash
curl "https://你的域名/run?index=0&token=你的密码"
```

`index` 从 0 开始，对应账号列表中的序号（可见的前 10 个）。

---


## 💬 Telegram 通知说明

配置 `TG_BOT_TOKEN` 和 `TG_CHAT_ID` 后：

* ✅ 定时任务（Cron）执行完成后，**汇总一次**发送通知  
* ✅ 面板批量执行（或调用 `/notify`）完成后，同样汇总发送  
* ✅ 单个手动执行 **不会** 单独发送通知，可进入面板查看结果  
* ✅ 通知包含每个账号的成功/失败详情及域名信息  

---

## 🧩 多 Worker 部署（管理超过 10 个账号）

每个 Worker 至多管理 10 个账号，若需管理更多：

1. 再创建一个新的 Cloudflare Worker  
2. 绑定一个 **新的 KV 命名空间**（建议），变量名同样为 `ALWAYSDATA_KV`  
3. 复制同一份代码，设置对应的 `ADMIN_TOKEN`（可与上一个相同或不同）  
4. 在新 Worker 的 KV 中填入另外的账号（最多 10 个）  

👉 多个 Worker 各自独立运行，互不影响。
